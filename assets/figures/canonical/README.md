# Канонические иллюстрации (Phase 5b)

Эта папка — документированный «слот» для личных копий защищённых авторским
правом рисунков из статей. Сами файлы **не коммитятся** (см. `.gitignore`);
книга публикует только цитирующие карточки `<figure class="canonical">`
рядом с соответствующим текстом, каждая со ссылкой на `references.html#papers`.

Если у вас есть легально полученная копия рисунка (например, скриншот из
открытого PDF статьи или personal fair-use копия для собственного изучения),
положите её сюда под именем из списка ниже — книга не проверяет наличие
файла автоматически (карточки сейчас текстовые, без `<img>`), но путь и имя
уже согласованы, чтобы при желании добавить `<img>` в карточку было
достаточно один раз проставить `src`.
