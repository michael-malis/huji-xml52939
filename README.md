# Statistical Perspectives on Machine Learning Interpretability

## 🔗 Live Site

**[https://michael-malis.github.io/huji-xml52939/](https://michael-malis.github.io/huji-xml52939/)**

## Description

A comprehensive, interactive study guide and handbook covering statistical perspectives on machine learning interpretability — from linear models and GAMs through tree ensembles, partial dependence and ALE, feature importance, Shapley values, local surrogates, saliency maps, concept-based explanations, example-based methods, and evaluation. Built as a self-contained, single-page-per-chapter reference with inline SVG figures, interactive Plotly charts, and MathJax-rendered mathematics.

## Author & Context

Created by **Michael Malis**, Statistics and Data Science program, The Hebrew University of Jerusalem (HUJI). Originally developed as a study companion for the Year 3, Semester A curriculum and later refactored into a standalone reference book.

## Tech Stack

- **HTML5** — one static page per chapter
- **Vanilla CSS / JavaScript** — no build step, no framework, shared asset layer (`assets/book.css`, `assets/book.js`)
- **[MathJax](https://www.mathjax.org/)** — mathematical notation
- **[Plotly.js](https://plotly.com/javascript/)** — interactive charts
- **GitHub Pages** — static hosting
