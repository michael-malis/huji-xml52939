## About & Acknowledgments

This is a personal exam-preparation project by **Michael Malis**, based on Course 52939, *Machine Learning Interpretability*, at the Hebrew University of Jerusalem. What began as a way to structure and consolidate course material has since been published as a standalone digital handbook.

Special thanks to **Prof. Yuval Benjamini**, who created and taught the course — the primary source and inspiration for this guide.
