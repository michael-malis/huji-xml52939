## Rules applied per file
1. Textbook flow: definitions before use; derivation chains; formulas as reasoning steps;
   conclusions derived, not announced; figure = next reasoning step; tables consolidate.
2. Symbol consistency: axis/legend/caption symbols identical to the adjacent formula;
   fixed features must not look varying; concrete plotted equation in caption only when a
   closed form exists.
3. Cross-lecture links folded inline as short clauses; no front-loaded recap block.
   Taxonomy sections kept.
4. Strict step→figure interleaving.
